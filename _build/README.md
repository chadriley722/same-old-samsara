# building sameoldsamsara.xyz

Everything is generated by `_build/build.py`. Jekyll skips folders starting with `_`, so nothing in here goes live.
Always `git pull` first. Edit `build.py`, never the generated HTML.

```
cd "Website/same-old-samsara"
git pull
python3 _build/build.py
git add -A && git commit -m "..." && git push
```

GitHub Pages rebuilds the site a minute or two after the push.

## when an episode goes live

Do this the same day the episode is public on YouTube, so "watch the newest episode" on the home page never points at an old one.

1. **Thumbnail.** Copy the live thumbnail to `images/epN-short-name.jpg` at 1280x720:
   ```
   magick "<the live thumb>.jpg" -resize 1280x720^ -gravity center -extent 1280x720 -strip -quality 80 images/ep5-short-name.jpg
   ```
2. **Episode entry.** In `build.py`, add one dict to the TOP of `EPISODES` (newest first):
   ```python
   {"id": "<11 character YouTube id>", "title": "lowercase title ending in a period.", "label": "season 1 · episode 5",
    "len": "mm:ss", "date": "YYYY-MM-DD", "img": "images/ep5-short-name.jpg",
    "blurb": "Two or three sentences, sentence case. No place names, no dashes."},
   ```
   The id is in the video's URL (`watch?v=<id>`). `date` is the day it went public.
3. **Build + push** (commands above).

That one entry updates the home page hero button, the films section, /films, /yt, /ig, /pin, the video schema and llms.txt.

## the walk (the 3D home page, branch `redesign-3d-b`)

The top of the home page is a loop trail you scroll along, drawn like a woodcut. All of it is in `walk/`, made in code, on made up ground (no model files, nothing from the real land). The html for the stops is in `build.py`: search for "the walk".

- **A new episode needs nothing extra.** The first screen's button, the films stop and the picture on the bedsheet screen all read `EPISODES[0]`.
- **Change a stop's words or links:** `walk_stops()` in `build.py`.
- **Change the ground, the trail or where things stand:** `walk/land.js`. Shapes are in `walk/mesh.js`, the light through the day in `walk/light.js`.
- **Preview:** `python3 _build/serve.py` then http://127.0.0.1:8811/ . Add `?plain` for the page without 3D, `?sky=night` for night, `?u=3` to stand at stop 3.
- **The 3D on its own:** http://127.0.0.1:8811/_build/walk-dev.html (arrow keys walk, `n` flips night).
- **If the look changes, redo the still prints** the plain page uses: run `python3 _build/serve.py 8811 127.0.0.1 --shots /tmp/walk-shots`, open `_build/walk-dev.html?shoot=1`, then turn each PNG into `images/walk/<name>.webp` at 1280 x 800 (`cwebp -q 80 -resize 1280 800 -metadata none`).
